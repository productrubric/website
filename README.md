# productrubric.com

The landing page for [ProductRubric](https://github.com/productrubric/product-rubric), served by GitHub Pages from this repository's main branch.

Plain static files, no build step:

- `index.html` — the whole page (the logo and favicon are embedded in it)
- `og.png` — the social share card the page references
- `CNAME` — the custom domain, productrubric.com

To change the page, edit `index.html` and commit. Pages republishes on every push to main.
