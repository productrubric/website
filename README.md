# productrubric.com

The website for [ProductRubric](https://github.com/productrubric/product-rubric), served by GitHub Pages from this repository's main branch.

Plain static files, no build step:

- `index.html` — the homepage and library
- `create.html` — Build a rubric, the browser rubric builder
- `cards.html` — Card decks, 147 cards across 4 decks, with deck boxes, spines, single-card detail pages, PDF downloads, share, and FAQ
- `og.png` — the social share card the page references
- `logo.png`, `favicon.ico` — logo and favicon
- `sitemap.xml`, `robots.txt` — search engine sitemap and robots rules, including `/cards`
- `llms.txt` — a plain text summary of the library for AI assistants, including the cards page
- `CNAME` — the custom domain, productrubric.com
- `demo-*.jpg`, `demo-*.mp4` — homepage demo recordings

To change a page, edit that page's file and commit. Pages republishes on every push to main.
